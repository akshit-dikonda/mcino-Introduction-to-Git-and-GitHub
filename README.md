# Simple Interest Calculator

## Project Description

This project is a Git and GitHub learning project that demonstrates
repository management, collaboration, branching, merging, pull requests,
and Bash scripting.

The project includes a simple interest calculator implemented using
a Bash shell script.

## Features

- Simple interest calculation
- User input for principal amount
- User input for rate of interest
- User input for time period
- Git and GitHub workflow practice
- Branching and merging
- Pull request workflow

## Simple Interest Formula

Simple Interest = (Principal × Rate × Time) / 100

## Technologies Used

- Git
- GitHub
- Bash
- Shell scripting

## Project Purpose

The purpose of this project is to demonstrate practical Git and GitHub
skills, including repository creation, collaboration, branching,
merging, pull requests, and basic Bash scripting.
